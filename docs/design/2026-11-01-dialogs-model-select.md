# 弹窗与模型选择器细化

用户要求沿用当前风格，细化新建评测、查看报告的间距、阴影、玻璃质感与动效，并由独立代理以用户视角试用。采用DESIGN.md既有材质/深度规范，主代理实施，独立代理只读审查与实机试用。

系统原生select弹出层不能可靠定制圆角和玻璃材质。模型/裁判改为无运行时依赖的select-only combobox，其余数字下拉保留原生语义。弹层DOM保留在原dialog内以维持焦点和事件边界，使用[原生manual Popover顶层](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API/Using)避开正文裁切；不支持该API时在正文可用范围内绝对定位。自适应上/下位置并在正文边界内限高，长名称换行、长列表滚动。模型身份仍是供应商和modelId的JSON组合，选中后沿用原snapshot接口及生成参数处理。

参考[WAI-ARIA Combobox Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)和[select-only示例的键盘约定](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/examples/combobox-select-only/)。只参考交互规范，未复制示例代码；官方示例的支持边界不视为本工具已完成辅助技术兼容验收。方向键浏览不提交值，Escape撤销浏览，确认后才请求快照。浮层内部滚动不触发锚点重新定位，防止滚动回弹。保留fieldSet原生禁用、焦点圈与对比模式回退。

标题与底栏使用克制玻璃边缘，成绩、答案、代码实底。桌面24/窄屏16内边距，配置/评分卡12圆角、模型浮层14，分层静态阴影；不改评分、执行队列、存储或正式时长逻辑。沿用短入场与按压动效，列表只淡入，减少动态效果时即时呈现。

验证顺序：新增键盘/取消/切换身份/长列表/裁判位置与明暗窄屏测试→完整UI、类型、构建→查看真实截图→备份后离线装入空闲Desktop→独立用户视角复测。原始用户界面和模型名称只保存在本地，公开截图仅合成测试数据。

## 工程验证

独立只读复核发现“重新确认同模型会清空部署版本/参数”，已用回归先复现再修正：已有有效快照且同模型时直接返回；失败无快照时仍可同值重试。补Enter/Tab/鼠标不重取快照、单模型失败重试/清错、空目录禁用、滚轮不回弹及Popover缺失回退。最终62项UI、类型检查、构建通过。1440/390明暗截图检查覆盖长模型名称、评分卡及浮层边界；辅助技术兼容矩阵和精确帧率未做实测。

alpha.10中间候选因打入ReactDOM渲染代码未通过HOST_REACT_CONTRACT，未安装、未发布，原包只在本地保留。移除该引用后，alpha.11实际包通过原校验：1441文件、零运行时依赖、资源manifest哈希不变。Desktop更新前完整备份1866个文件（含profile五文件及历史）；安装后1441文件匹配、1851非锁历史文件逐字节未变；重启后1849相同、两份摘要仅revision变化。
