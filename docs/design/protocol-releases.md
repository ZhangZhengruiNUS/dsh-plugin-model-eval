# 评测版本与归档

评测版本按类别和可选档位独立登记。有档位的类别按档位升版，单套题集的类别直接升版。首发候选包含三个系列。

| 系列 | 对外名称 | 首发协议身份 |
| --- | --- | --- |
| 通用能力评测 / 轻量 | 通用能力评测 · 轻量 1.1 | `general-task-five-original-v1-light` |
| 通用能力评测 / 深入 | 通用能力评测 · 深入 1.2 | `general-task-five-original-v1-deep-r2` |
| 中文写作 | 中文写作 1.0 | `work-writing-12-v2` |

深入 1.2 纳入插件 0.1.0，修订了五道编程题，仍为 348 题。轻量 1.1 保留完整协议和题面。深入 1.1 保留原身份供已有报告与任务使用。通用 1.0 的旧题由安装过对应资源的用户从本机缓存读取，按原准备清单逐文件校验后可继续既有任务。中文写作的旧题集保留 `work-writing-12-v1` 及「旧版」名称。

版本筛选由当前可用的目录与可查看的历史成绩提供。某一版本尚无成绩时也显示名称，结果区展示空态。上下文已明确类别时使用「轻量 1.0」或「深入 1.0」等短名，独立出现时使用完整名称。题量与题目来源在「评测方法」和「评测依据与计分方式」中查看。

| 变更 | 版本处理 |
| --- | --- |
| 界面、安装、日志等不改变评测定义和测量含义 | 只升插件包版本。插件继续使用 SemVer，例如 `0.1.0-rc.1` |
| 修正可改变原答卷判分的缺陷 | 升受影响系列的补丁版，例如 `1.0.1`，保留旧成绩与复判来源 |
| 更新题集、提示或规则，维持同一测评体系 | 升受影响系列的次版本，例如 `1.1`，记录题集及规则变化 |
| 重定义能力维度、聚合方法或主要测量口径 | 升受影响系列的主版本，例如 `2.0`，写明与旧版的解释边界 |

成绩按内部协议身份、评分定义及原有比较条件分组。通用能力绑定档位协议 ID、资源身份与定义指纹。中文写作按写作 ID 分组，保留裁判条件。已有报告和暂停批次继续引用写入时的身份。跨版本对照使用核验过的共同题或有来源的复判证据。

## 下一次协议发布

1. 冻结受影响系列的新题集、提示、题量、评分定义及资源指纹。通用档位在 `src/evaluation/current-edition.ts` 登记对外版号、档位、完整身份和评分 schema。中文写作在 `src/evaluation/writing-edition.ts` 登记独立写作 ID、版号和题量。可随包保留的旧写作题集在资源清单的 `writingArchives` 按旧 ID 登记并验证文件指纹。需要本机归档的旧题集沿用原资源读取规则。资源与评分行为通过验收后切换该系列的当前版本。
2. 验证首装和升级。首次打开新建评测时，后台准备各档位的当前通用资源，共用的资源版本只准备一次。中文写作资源仍按需准备。切换单个系列后，检查其他系列继续读取原版本。通用归档设置沿用此前偏好，新目录显示各档当前版本，有本机旧通用记录时可恢复查看。
3. 复核历史、续测及内置参考。参考需匹配同一档位的完整身份与定义指纹。新版本若需要内置参考，按该版本核验成绩、原答卷来源与评分口径后再登记。随成绩展示的平均任务耗时须能从同轮已提交的逐题记录完整重算，整轮用时单独记录。
4. 记录实际发布日期、系列与版本、首个承载该版本的插件、受影响的定义及可复判范围。插件候选、本机宿主验证与公开发布各自登记。

参考做法：[SemVer 2.0.0](https://semver.org/spec/v2.0.0.html) 用于插件包版本；[MLPerf Endpoints](https://docs.mlcommons.org/endpoints-submission-docs/reference/benchmarks/) 将基准套件版本与其测试定义一起列明。
