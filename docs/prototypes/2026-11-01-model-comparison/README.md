# 模型比较交互样稿

2026-11-01。用户选择先用合成数据体验比较流程，再决定正式界面的实现细节。

入口为 [index.html](index.html)。完整 HTML、CSS、SVG 和脚本均在同一个文件，没有外部图表库、字体或运行时下载。浏览器预览通过本地 visual companion 提供；会话 URL 只在聊天中提供，不入仓。

## 可以体验

- 能力分 / 响应耗时散点，切换正文首字等待；点选查看精确值、配置与报告。
- 最多三个关注配置，稳定色标联动；星标选择差值基准。
- 通用四轴、写作五轴雷达，切换精确正负差值；保持各自量尺。
- 可排序的成绩矩阵、候选搜索和缺失/部分用量状态。搜索保留已选配置，窄容器提示横向滚动。
- 单配置演示报告、同配置合成历史与运行条件。
- 多模型、单模型、暂无成绩、条件不同、分数接近、坐标重合六种场景。
- 宿主窄容器、暗浅主题、减少动态效果；系统减少动态效果偏好同样生效。

所有模型、供应商、分数、Token 和历史均为合成示例，不代表任何真实模型。新建评测和其他导航只提示样稿边界，不启动真实任务。交互状态只留在页面内存中，刷新即重置。

## 验证记录

主代理使用 Playwright 浏览器连接器实际操作本地预览，24 项流程断言通过，覆盖选择上限/菜单焦点、搜索保留、带符号差值、两轨道单模型/空态/混合条件、重合点逐项选择、首字等待切换、报告打开/滚动/焦点/Escape、搜索空态、390px 无页面横向溢出、矩阵横滚提示及键盘滚动、系统减少动效。另验证报告重开回到顶部。

逐一检查两轨道 × 六场景；单模型不伪造对手，混合并发/未知条件或不同裁判不连接统一边界。没有响应数据的记录保留在矩阵，未填零绘点。

实际查看 1440px 宽屏、约 752px 内容宽的宿主模拟、390px 窄屏及暗浅主题截图。修复了玻璃选择条的菜单层级、拒绝第四项后的复选状态、窄屏溢出、搜索后隐藏选择、报告重开滚动位置、横滚可发现性及趋势标签间距。

独立 screen_operator 原计划使用 Computer Use 实际试用，但工具无法可靠确认 Windows 浏览器 URL，按工具要求停止，未重试该通道。之后仅检查四张静态截图，提出散点点选提示、矩阵横滚提示、历史标签间距三项意见；三张最终截图复核确认这些可见问题收敛。独立交互验收未完成，不将截图复核写成实机试用通过。

浏览器控制台最终无错误/警告。浏览器工具禁止 `file:` 导航，所以自动化未验证直接双击本地文件；实际验证范围是 localhost 预览。该限制未被绕过。
