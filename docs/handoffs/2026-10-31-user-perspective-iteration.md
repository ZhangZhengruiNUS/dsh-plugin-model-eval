# 2026-10-31 用户视角试用与迭代

独立 screen_operator 按 computer-use 技能操作真实 DSH Desktop 0.2.1-rc.5，以用户视角试用 alpha.3、复测 alpha.4，最终聚焦复测 alpha.5。主代理负责代码修改和安装，操作期间每次明确移交桌面控制权。

## 发现与改进

| 用户试用发现 | 最终行为 | 验证 |
| --- | --- | --- |
| 待补测只有中断码，不知道下一步 | 展示已知中断环节；原因未记录时明确说明，解释继续与更换裁判用途 | 界面回归与真实任务页复测 |
| 长列表选题后找不到详情 | 选中及异步详情加载完成后定位；详情保留阅读空间，可返回原筛选列表 | 延迟加载夹具先失败后通过；alpha.5 实机复测 |
| 整轮未完成与单项已有成绩混淆 | 区分整轮完成统计与所选轨道最近完整成绩 | 实机看板复测 |
| 宿主侧栏挤占空间后表格藏列 | 根据容器实际溢出显示横滚提示，固定模型身份列，增强滚动条 | 1280×753 实机、窄容器回归与明暗/移动夹具 |
| 参数格式、测速额外用量与宽范围难懂 | 参数作用/停止词 JSON 示例；按轨道显示每配置最多 8/4/12 次调用；解释小样本范围 | 实机新建与测速历史复测 |
| 历史轨道/状态小字难辨 | 增大字号与行高 | alpha.5 实机可辨，未见上下裁切；未推断旧渲染根因 |

alpha.4 复测仍发现详情标题停在弹窗底部：首次定位发生在加载占位阶段，加载结束后没有再次定位，且短详情缺少足够滚动空间。alpha.5 补齐定位时机及阅读高度后，回答和判分证据直接可见，返回后筛选保留。复测期间未新增模型调用、恢复正式任务、清理数据或修改设置。

## 边界与下一步

本轮完成用户视角的界面与操作理解改进，不改变评分、估时算法、生成参数身份或存储格式。正式动态 ETA 的真实误差、完整中文写作补测和真实数据清理仍未验证；界面夹具与真实浏览不能替代这些验收。下一步应结合下一次真实评测，对比开始前范围、运行中变化与最终耗时，决定是否需要校准估时；不要为此自动补跑整轮或清理历史。
