# 模型对比页升级交接

用户明确调用 ui-pilot 和 frontend-copy-audit 进行界面优化。以模型对比为代表页，保持已确认的专业数据工具方向；[DESIGN.md](../../DESIGN.md) 为本仓唯一界面实施规范，[调研与文案审核](../ui-pilot/2026-10-31-comparison/research.md) 保存来源、取舍和验证边界。

## 最终变更

- 大统计卡收成概览条，不补零；整轮与单轨道定义按需展开。
- 轨道、协议、搜索与方法集中于成绩区域，删除重复副标题及底部说明，必要适配与裁判限制保留在方法中。
- 支持按模型、供应商和部署搜索，显示筛选数量，区分无完整成绩与无匹配。
- 模型名称可直接打开报告，窄屏无需寻找末列按钮；返回时焦点可见。固定模型列、主分强调、数字右对齐，明确耗时单位与Token口径。
- 保留可见参数及完整含义提示、长名称换行、混合裁判/自评和缺失数据。
- alpha.6实机发现已有写作待补测时空态仍引导新建。alpha.7改为已有未完成任务时显示“查看评测任务”，没有已有任务才引导新建；新增用例先失败后通过。
